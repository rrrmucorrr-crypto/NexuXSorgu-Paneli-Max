# NexuXTanrı 𖤟 SorguPaneli

> **ULTRA PREMIUM CYBER-DARK SENTETİK DEMO VE İSTİHBARAT YÖNETİM PLATFORMU**

NexuXTanrı 𖤟 SorguPaneli, siber sistem estetiği (obsidyen `#050609`, vişne kırmızısı `#C8103D`, metalik gümüş `#C8CDD5`, buz mavisi `#84D9FF` ve VIP altını `#B99A5E`) ile inşa edilmiş, **12 kategori** ve **101 sentetik sorgulama modülünü** eksiksiz barındıran profesyonel bir web uygulamasıdır.

Uygulamanın tamamı **%100 deterministik sentetik veri motoru** ile çalışır. Hiçbir gerçek kişisel veri (PII), sızdırılmış veri tabanı veya dış yetkisiz API bağlantısı içermez.

## 🚀 Başlıca Sistem Özellikleri

- **Özelleştirilmiş Formlar & Çıktı Düzenleri:** Her sorgunun kendi alan tanımları, doğrulama kuralları, "Örnek Veri Doldur" butonu ve amaca uygun görsel şablonu (Soy Ağacı Düğümleri, Zaman Çizelgesi, Dosya, Tablo, Finansal Özet vb.) vardır.
- **Rol Tabanlı Erişim Katmanı (RBAC):** `FREE`, `PREMIUM`, `VIP`, `ULTRA`, `YONETICI`, `ADMIN`. Kilitli modüller için özel yükseltme penceresi ve anlık test rol değiştirme olanağı.
- **Erişim Anahtarı (Key) Sistemi:** Admin panelinden 1 Gün, 7 Gün, 30 Gün veya Sınırsız süre ve kota tanımlı lisans anahtarı oluşturma, etkinleştirme, süre uzatma ve iptal etme.
- **Dışa Aktarma Araçları:** Sentetik sonuçlar için tek tıkla geçerli JSON İndirme, formül enjeksiyonu korumalı CSV İndirme ve Yazdırılabilir Dosya görünümü.
- **Değiştirilemez Denetim Günlüğü (Audit Logs):** Oturumlar, sorgulama başlangıçları, rol yükseltmeleri ve lisans anahtarı atamaları tam kayıt altındadır.
- **Mock Veri Motoru Kontrolü:** İstemci ve sunucu için simülasyon gecikmesi (ms), test hata oranı ve deterministik tohum ayarları.
- **RESTful API ve MySQL 8:** Next.js App Router API uç noktaları (`/api/queries/catalog`, `/api/queries/run`, `/api/admin/health`) ve 18 tabloluk tam DDL şeması (`database/schema.sql`).
